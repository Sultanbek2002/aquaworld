# GLB-модели (необязательно)

Игра работает без внешних моделей: все персонажи и животные процедурные.
Чтобы заменить модель на свою, положите `.glb` в эту папку и добавьте запись в `manifest.json`:

```json
{
  "models": [
    { "id": "lilia", "file": "models/lilia.glb", "scale": 1, "rotationY": 0, "offset": [0, 0, 0] }
  ]
}
```

- `id` — персонаж (`diver`, `lilia`, `oceana`, `arachna`, `guardian`) или вид животного из `SPECIES` в `js/data.js` (`turtle`, `dolphin`, `manta` и т. д.).
- Модель должна смотреть вдоль +Z, голова вверх, рост дайвера ≈ 2 единицы.
- Если в файле есть анимация с именем, содержащим `swim` или `idle`, она проигрывается автоматически (иначе — первая).
- Загрузка работает только через сервер (Live Server); при открытии файла напрямую остаются процедурные модели.
